# TaskFlow ✅

## 💫 About The Project

**TaskFlow** is a modern task management application built with React and TypeScript.

The project allows users to create, manage, and organize their tasks through an intuitive interface with authentication, CRUD operations, and efficient state management.

The main goal of the project was to build a scalable frontend application while practicing advanced React patterns, API integration, and modern state management solutions.

---

## ✨ Features

### 👤 User Features

- 🔐 User authentication
- 👥 Protected routes
- 👤 User-specific task management

### ✅ Task Management

- ➕ Create tasks
- ✏️ Edit tasks
- 🗑️ Delete tasks
- 📋 View task lists

## 🚀 Getting Started

### Clone repository

```bash
git clone https://github.com/BohdanKrav4enko/TaskFlow.git
```

### Install dependencies

```bash
pnpm install
```

### Start development server

```bash
pnpm dev
```

---

## 📦 Production Build

Create an optimized production build:

```bash
pnpm build
```

Preview production version:

```bash
pnpm preview
```
